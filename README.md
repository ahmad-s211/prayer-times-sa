# prayer-times-sa
A responsive web application displaying daily prayer and Iqamah times across Saudi Arabian cities using Aladhan API and Vanilla JavaScript.

## ✨ Features
* **Real-Time Data:** Fetches live, accurate prayer schedules integrated with the Aladhan REST API.
* **Smart Calculations:** Automatically computes Iqamah times and converts 24-hour timestamps to localized 12-hour Arabic formats.
* **Persistent Preferences:** Uses `localStorage` to save and restore the user's selected city across browser refreshes.
* **Fully Responsive:** Seamlessly optimized for desktop, tablet, and mobile displays.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox & Media Queries)
* **JavaScript (ES6+)**
* **Axios** (HTTP client for API requests)
